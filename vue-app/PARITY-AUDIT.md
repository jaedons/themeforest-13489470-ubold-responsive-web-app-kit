## 验证结果

- `npm run build`：类型检查及生产构建通过。
- Vue 单元测试：9/9，包含筛选后编辑页码恢复及排序清除选择。
- Playwright：120/120（101 个旧地址迁移、未知地址恢复、原有 11 项交互及新增 7 项对照回归）。路由检查包含页面错误和缺失资源检测。
- 原静态项目：101 页面组件同步检查、7/7 测试、资源与语法检查通过。
- `npm run format:check`、`git diff --check`：通过。
- 手动浏览器核验：通知抽屉、全部已读、跳转至对应邮件；开发预览商品编辑、日历、仪表盘加载。
